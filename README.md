Agentic AI Chatbot using Qwen and MCP

Project Overview

An Agentic AI chatbot built using the Qwen Large Language Model (LLM) and Model Context Protocol (MCP). The chatbot integrates AI tools to perform tasks and provide intelligent responses.

Technologies Used

- Python
- Qwen 2.5
- Model Context Protocol (MCP)
- Ollama
- Gradio

Features

- AI-powered conversations
- Tool integration using MCP
- Mathematical calculations
- Word counting
- Web search integration
